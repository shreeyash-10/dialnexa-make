# Brand asset needed

Add the official DialNexa app icon here as `dialnexa-make-icon.png` before creating or reviewing the app.

Make requires a PNG that is:

- square;
- between 512 × 512 and 2048 × 2048 pixels;
- no larger than 500 kB.

Use the official DialNexa artwork and confirm trademark/brand authorization in the review form. Avoid inventing or redrawing the logo for the directory submission.
